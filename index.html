Assistance SamaStore

SamaStore aide les petits commerces à gérer leurs articles, leurs stocks et leurs ventes.

Utiliser SamaStore

  • En mode local, ajoutez un article, puis ouvrez la caisse pour enregistrer une vente.
  • Pour lire un code-barres ou un code QR, ouvrez le scanner et autorisez la caméra. Vous pouvez aussi saisir le code à la main.
  • Pour rejoindre un espace partagé, utilisez le compte fourni par le propriétaire du commerce.

Obtenir de l’aide

Ouvrir une demande d’assistance. Indiquez votre version de SamaStore et les étapes qui reproduisent le problème. GitHub peut demander un compte et les demandes sont publiques. Ne publiez aucun mot de passe, reçu, renseignement personnel ou fichier de votre commerce.
